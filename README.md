# Product Explorer

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

## Features
- Product listing
- Search functionality
- Category filtering
- Price sorting
- Product details modal
- Loading state
- Error handling
- Responsive UI

## API Used
https://fakestoreapi.com/products

## How to Run

npm install
npm run dev

AI tools were used for guidance, debugging, and improving UI structure. All code was reviewed and understood before submission.
